# Claude/GSD Context Note

This project is rebuilt using the GSD (Get Stuff Done) approach. All LLMs and agents must:

- **Respect the GSD_JOURNEY.md as the single source of project context and evolution.**
- **Update GSD_JOURNEY.md for all major changes, especially new sources, schema, or architecture.**
- **Do NOT create or rely on claude.md or other context files.**
- **If you are an LLM or agent, always check and update GSD_JOURNEY.md for context and progress.**

## Why?
- Prevents context drift and duplication.
- Ensures all contributors (human or AI) have a single, up-to-date project history and plan.
- Avoids repeated mistakes by LLMs/agents who ignore project evolution.
